Overview

This project is a runnable, dependency-light reference implementation of the paper "Explainable Agentic RAG for Financial Risk Analysis." It extracts a knowledge graph from financial documents, answers risk questions through a verification-gated multi-agent loop, and backs every claim with quantitative models and traceable provenance — instead of an LLM guessing numbers.

This page is a static, single-file summary of the project meant to be readable without running anything. The real interactive graph/metrics dashboards are generated locally by demo_dynamic_kg.py (see below) and are not checked into the repository.

How to Run

# 1. Create a virtual environment and install dependencies
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. Run the offline demo (no API key, no GPU required)
python demo_dynamic_kg.py --backend mock

# 3. Run the test suite
pip install pytest
python -m pytest tests/ -v

# 4. Open the generated visualizations
#    - kg_graph_improved.html  (interactive knowledge graph)
#    - kg_metrics.html         (metrics dashboard)

See README.md for the full guide, including how to switch to a real LLM backend (Ollama, Hugging Face, or Anthropic).

Pipeline

  1. Load documents — PDFs are parsed and tagged by type (10-K, 8-K, earnings, ...).
  2. Extract the knowledge graph — entities (companies, subsidiaries, risk factors) and relations (SUPPLIES, GUARANTEES, OWNS, EXPOSED_TO) are extracted with a confidence score; high-impact relations require >75% confidence to enter the production graph.
  3. Plan & retrieve — the query is decomposed into sub-tasks; each sub-task retrieves dense passages and graph evidence.
  4. Reason & verify — a claim is drafted, checked against the evidence, and retried if confidence is too low.
  5. Explain — the final answer is returned with full provenance (source documents, graph paths, confidence).
